# Ручная проверка GUI (Release)

Автотесты (`run_tests.bat`) проверяют движок, кодоген, сессии и вкладки без окна. Отрисовку ImGui, мышь и
сохранение настроек они не видят — это проходится руками перед релизом и после правок `gui*.cpp`.
Отметки ставить в копии файла; что не так — записать рядом (что сделал, что ждал, что увидел).

## Запуск и настройки
- [ ] `x64\Release\U-CUDA.exe` стартует, русские подписи читаются (нет квадратиков).
- [ ] Settings: «Use LaTeX for parameters and variables» выкл/вкл — имена полей переключаются между
      `vc_c1` и формулой, после перезапуска выбор сохранён.
- [ ] Settings: «Initial conditions of algebraic variables (DAE)» выкл — у ДАУ в Analysis / System нет полей z,
      есть строка «N algebraic variables hidden»; вкл — поля z на месте.
- [ ] Settings: rdc (раздельная сборка) выкл — первый расчёт Parametric на Лоренце собирается за секунды
      (монолит с отсечением ядер), вкл — тоже секунды.

## Library / System
- [ ] Выбор Lorenz, Generate для нескольких схем (RK4, CD, CD fast, DOP853, Implicit Midpoint) — тела без ошибок.
- [ ] Поля параметров и НУ принимают приставки СИ: `10k`, `4.7u`, `2meg`, `1m` (милли) / `1M` (мега);
      неверное (`5asdf`, `1kk`) — подсвечено и не принято. ↑/↓ меняет цифру под курсором и сохраняет приставку.
- [ ] Окно Groups: вкладки Parameters / Initial conditions, перетаскивание групп мышью (порядок сохраняется
      в записи), подписи LaTeX в столбце label, «shown as» показывает формулу.

## DAE и схемы
- [ ] Library → DAE: Mikhailov DAU_n — превью уравнений (дроби, точки над переменными, 10^{k}), чекбоксы методов,
      Generate печатает все методы (неприменимые — с причиной).
- [ ] Circuit → Open: `.cir` и `.kicad_sch` (с KiCad) импортируются, отчёт импорта, Watch подхватывает правку файла.
- [ ] multivibrator: группы НУ (Capacitors, Devices/…, Algebraic свернута), подписи vc_{C1}, R_{1}; значения
      R / C с приставками (15k, 10u).
- [ ] «Ideal op-amps», «Save ideal copy», упрощения приборов (без C переходов / идеальные диоды / BJT) и
      «Save simplified copy» — новые записи в библиотеке.
- [ ] «DC operating point» на транзисторном каскаде — значения узлов меняются, ошибок нет.

## Analysis
- [ ] Лоренц, RK4, GPU и CPU: фазовый портрет 2D / 3D, временной ряд; подписи осей формулами, легенда.
- [ ] Адаптивный шаг (DOP853, BDF 1-5): проекция Step size показывает h(t) с того же t, что и траектория.
- [ ] ДАУ (DAE-2 Pendulum, Radau IIA; DAE-1 PUT burst neuron, BDF 1-5): счёт без ошибок, строка о согласовании
      начальных значений; Stop прерывает длинный расчёт и оставляет старые графики.
- [ ] Time domain: дерево переменных по группам, ПКМ по группе — Select all / Deselect all / Only these.
- [ ] Комбо осей Phase 2D / 3D и переменной признака: формула в превью не вылезает за рамку.

## Parametric / Basins / Metrics / DFT
- [ ] БД 1D / 2D, LLE 1D / 2D, LS 1D / 2D, Metrics на Лоренце: классика и continuation, GPU и CPU, прогресс-бар
      доходит до конца, Stop работает, CSV-экспорт открывается.
- [ ] Те же вкладки на ДАУ (DAE-1 Nonlinear coupling, BDF1 и адаптивный Rodas4): ось по z отклоняется с сообщением.
- [ ] Basins (Лоренц / Faiza): карта, кластеры, повторная кластеризация.
- [ ] DFT: классика, continuation, свип по h.
