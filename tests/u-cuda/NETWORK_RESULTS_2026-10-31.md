## Корректность

24 случая FHN/HR × Euler/RK4/CD × Ring/Star/Chain/SmallWorld прошли:

- повторные запуски совпадают побитово;
- новая версия совпадает с baseline исходного движка;
- чанки 1, 7, 13, 64, 1000000 дают побитово одинаковые результаты;
- включение GPU-таймера не меняет результат;
- проверены временная сетка, траектории, статусы, диапазоны, отсутствие разлёта;
- отрицательный размер чанка отвергается.

Контроль инструмента сравнения: изменение одного байта в копии дампа
отвергнуто с кодом 1 и указанием первого несовпавшего байта.

Одиночный HR при `h=0.01`, `T=10.24` совпал с независимым CPU RK4
с допуском `1e-9` на обеих версиях движка. Используется уравнение
`y'=c-d*x*x-y`.

Release-сборка, `gpu_smoke` и `architecture` прошли. Существующий тест `tabs`
остановился при загрузке JSON: на машине отсутствует
`U-CUDA/library/Dahlquist 2D/system.json`. Он не прошёл; новые проверки Network
от локальной библиотеки не зависят. Debug не собирался: сигнатуры hostLibrary
не менялись, проверяется путь современного приложения Release.

## Производительность

RK4, кольцо степени 4, 1024 шага, запись каждого четвёртого шага, 257 точек.
Три серии по девять измерений, перед каждой не менее 300 мс прогрева.
Ниже минимум / медиана / максимум, мс; все 162 измерения сохранены в
[CSV](fixtures/network-benchmark-2026-10-31.csv).

| Модель | Узлы | GPU, мс | Полный вызов с выгрузкой, мс |
|---|---:|---:|---:|
| FHN | 16 | 5.360 / 6.276 / 22.884 | 14.686 / 15.674 / 32.006 |
| FHN | 64 | 5.084 / 5.405 / 6.845 | 13.490 / 14.536 / 14.628 |
| FHN | 256 | 10.126 / 10.450 / 12.787 | 23.981 / 25.179 / 26.099 |
| HR | 16 | 3.375 / 3.394 / 47.338 | 14.399 / 15.475 / 62.645 |
| HR | 64 | 4.240 / 4.899 / 6.333 | 12.790 / 13.246 / 13.911 |
| HR | 256 | 10.212 / 12.153 / 12.542 | 20.945 / 22.570 / 22.864 |

У всех измерений один запуск ядра. GPU-время — интервал CUDA events вокруг
запуска; полное время включает выделение памяти, передачу входов, ожидание,
выгрузку и обработку результата. Компиляция прогрета и в замер не входит.

В случаях на 16 узлах видны большие выбросы, несмотря на прогрев. Причина
этими измерениями не установлена; частоты и системная нагрузка не фиксировались.
Поэтому небольшие различия между размерами не считаются устойчивым выигрышем.
Это baseline конкретной нагрузки, а не оценка скорости больших сетей.
