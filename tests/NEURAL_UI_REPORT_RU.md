# Единый интерфейс Neural

## Что сделано

- **Neural Controls** использует общую структуру для всех экспериментов.
  Вкладка **Task** идёт первой и содержит имя эксперимента и выбор задачи.
  В **Input** находятся источники, загрузка CSV для классификации, протокол
  и маршрутизация. **Network** содержит интегрирование, популяции и связи.
  **Readout** показывает параметры выбранной задачи. В **Analysis** собраны
  запись наблюдений, свип, показатели Ляпунова и сводка последнего запуска.
- **Run**, **Run all** и **Stop** видны при прокрутке настроек. Кнопка **+**
  добавляет эксперимент через тот же механизм вкладок, что и в Parametric.
- **Neural Results** показывает доступные представления по данным
  завершённого прогона. Для классификации доступна цветная матрица ошибок
  с числами и процентами по строке. Ширина столбцов задана независимо
  от экземпляра свипа. Для внешнего CSV клик по ошибке открывает ID образцов
  из завершённого прогона. Сравнение конфигураций использует совпадение
  тестовых входов и меток.
- Отдельный режим интерфейса MNIST удалён. Сохранённую конфигурацию на 560
  узлах можно открыть через общий интерфейс по [гайду MNIST](../resources/NEURAL_MNIST_RU.md).

## Проверки и продолжение

Итоговая настольная сборка Windows Release|x64 и сборка целей
`neural_classifier_test` и `neural_results_test` прошли. `git diff --check`
прошёл. В более ранней версии интерфейса прошли 15 выбранных проверок
на RTX 2060 SUPER. После перехода на единый интерфейс автотесты
отложены до открытия PR.

Сохранённая столбцовая конфигурация на пилотном CSV дала 36 из 50 правильных
ответов в пакетном запуске. Полный MNIST в этой работе повторно не запускали.

Перед PR выполнить [ручную проверку Neural Results](README.md#neural-results-and-spike-statistics).
Особенно проверить переключение задач, добавление эксперимента через **+**,
запуск из любой вкладки, переключение экземпляров свипа и соответствие ID
выбранной ячейке матрицы после замены CSV. Затем запустить регрессионный набор.
