# Local data rules

- Treat library/ as user-owned data.
- Never delete, rewrite, migrate, format, or commit its contents.
- Do not add source code or build definitions to this directory.
- Put distributable systems in resources/library_template/.
- Put runtime logs in ignored locations and do not use them as test fixtures.
- Read [resources/README.md](../resources/README.md) before changing library seeding behavior.

See [the local-data README](README.md) and [the root architecture](../ARCHITECTURE.md).
